## 🚀 Features
- [x] **Basic Visual Studio Setup:** From nothing to working code.
- [x] **OpenGL Assembly:** Draw our first triangle / Draw our first 3D shape.
- [x] **Block-based Rendering:** Concise understanding of how to efficiently draw blocks.
- [x] **Chunk-based Rendering:** Drawing Optimized Chunks, and learning how to erase invisible faces.
- [x] **World-based Rendering:** Optimizing Chunks to work globally, and creating a world manager.
